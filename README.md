# 仲春仿宋

![](https://forum.han-zi.top/assets/files/2025-05-02/1746189090-832406-b1445830-c895-4973-9783-3667f4c71bb6.jpg)

「仲春仿宋」項目是對上世紀聚珍仿宋二號長體鉛活字字形進行的數字化。採用直接復刻辦法，從印刷品掃描件中提取字形並封裝爲字體。

項目尚處於開發和測試階段，其中的缺字、醜字不少，遠不及正式版發佈的程度。簡化字部分是基本沒有的，也不太推薦用於現代漢語文本的排版，還請各界朋友多多包涵。

## 開發故事

若論哪套長體仿宋最爲著名？熟諳近現代印刷史的同志，恐怕大都會脫口而出「聚珍仿宋」。不過聚珍仿宋的長體鉛字自身又包含多種字號，哪一種最具代表性？這個問題的答案或許在同志們的腦海中能浮現出，但落實到具體字號層面，就不那麼好回答了。

聚珍仿宋二號長體鉛字，造型妍美多姿，而又因其字號適中，常應用於正文排版而不是標題和夾註。相比於頭號字的直健、三號四號字的間架異化處理、五號字的細密，二號字的字形可以說是最豐富地展現了聚珍仿宋家族的風味。同時，上世紀末，聚珍仿宋二號長體經過史雲鵬的大力推廣，成爲了工程類製圖常用的手寫體。工科出身的朋友們，你們當年有沒有練習過呢？

聚珍的頭號方體長體、二號方體，市面已有產品，而尚無二號長體產品可用。

在印刷品樣本方面，現在開放的電子化掃描件非常多了，缺少的只是對其中的字形進行提取封裝的工作。這個工作量不小，所以從今年（2025）1 月開始，我們又合作開發了一種切片工具和一種封裝前處理工具，效率大爲提升，小組內的同志們拊掌稱奇。

總之，「仲春仿宋」是傳統漢字美學、印刷和數字化技術、新生產力結合的產物。

> 問：「爲什麼要叫『仲春』」呢？<br>
> 答：這個項目是乙巳年仲春開始進行的。此外「仲」有「排行第二」的意思，而「春」的聲符「屯」又有「聚集」的意思；二者結合，與「聚珍二號」暗應。「Sotyr」是「聚珍」的諧聲域。
