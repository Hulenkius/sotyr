夫銷金繼梓，易木爲鉛者，近世之活字印法也。隶至清亡，吳人丁氏昆仲倣宋栞歐字鑄「聚珍倣宋」，是「宋朝体」之始，其制多矣。我人造爲「仲春仿宋」者，即聚珍倣宋之二號長體。逕擷字於群書，故字不潔云。復令 [zi2zi-JiT](https://github.com/kaonashi-tyc/zi2zi-JiT) 洎 [HanziGen](https://github.com/wangwenho/HanziGen) 摶靈筆（AI）以爲代匱佐闕。

**執草未就**，而闕字生焉，而媸字生焉，未可言其竟。君子觀之，願得所正。

## 紀

或問曰：「倣宋字之長者，誰彰？」君子對曰：「聚珍倣宋。」復問曰：「聚珍有所宏微，誰顯？」曰：「我知之，而不能具説。」

聚珍之二號長體，實妍極之寶。以其不喧於題、不奪於註，盡聚珍之態，天下多用之。卅歲以往，有善書史氏雲鵬者盛揚之，則營人經之、巧人憑之。邦中今之工者，抑曾有所習焉。

聚珍之頭號方體、長體，二號方體，前人已備矣，而二號尚闕。

今萬維之世，秘書徧於隈隅，人盡可得之，而擷字不能速。今歲仲春，我人乃作刃一、圅一，擷字如飛，同儕奇之。

v0.16-beta 之出也，遐邇之士，咸來取用，廟堂閭里，或有譏讚，以期速就。

王公、橘公告曰：「夫水行莫如用舟，而陸行莫如用車。今柳公行絹帛之上，非一刃、一圅之能成也。宜摶靈筆，降神工，則速就矣。」乃驅 [zi2zi-JiT](https://github.com/kaonashi-tyc/zi2zi-JiT) 與 [HanziGen](https://github.com/wangwenho/HanziGen)。字形蕃殖，點捺孳乳，蓬蓬乎萬八千乃止。然則靈文難跡，素筆易封，柳公宵夜圖畫，緩成 v0.22-beta 之實，甚可喜也。

嗚呼！古賢今才之德，我人所不能及也。姑獻此字，後之博雅，將有所用乎？

> **問曰**：「何以名『仲春』？」<br>
> **對曰**：乙巳仲春始經之。而「仲」者「弟二」也，「春」從「屯」者「聚」也，并言之「聚珍二號」也。「Sotyr」者，若「聚珍」之古聲也。
